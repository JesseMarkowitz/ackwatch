# ADR-0001: Apache-2.0 project license

- Status: Accepted
- Date: 2026-08-31

## Decision

AckWatch is licensed under Apache License 2.0. Dependencies must have compatible terms. AGPL
reference applications may inform protocol research but their source is not copied into AckWatch.

## Consequences

The repository carries the full license, package metadata uses `Apache-2.0`, and the dependency
report rejects AGPL packages. Trademark questions remain separate from copyright licensing.
